# SPC to 3D — ICIP 2025 Project Page

The project page is GitHub Pages-ready. The video is embedded from Google Drive, so the large video file does not need to be uploaded to GitHub.

## Video
Google Drive: https://drive.google.com/file/d/1dG8m4VGTizSqCDo7YobSxzJEuri-GCGS/preview

**Before publishing:** In Google Drive, set the video's sharing permission to **Anyone with the link → Viewer**.

## Publish
1. Create a public GitHub repository, e.g. `spc-to-3d`.
2. Upload the contents of this folder to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch → main → /(root)** and save.
